# Using Trackypady

Start with **Try gesture demo** to explore touch gestures and feedback on iPhone without a Mac. Follow the guide; swipe left/right to revisit demo steps. The demo simulates the composer and actions—it does not send anything to Codex.

For live use, install the official Mac bridge, allow Bluetooth and Accessibility, and scan the bridge QR from **Scan to pair** on iPhone. Keep Codex installed and signed in on the Mac. A connected status and the phone’s eyes indicate the connection; try bringing Codex forward before dictating.

A typical loop is: hold to dictate, release to finish transcription, review the text in Codex, then swipe up to send or down to select/discard according to the current state. Follow the bridge’s gesture guide for exact touch and hold settings; it also explains Queue and scratch-to-stop. Verify the intended draft in Codex before sending. Feedback acknowledges the gesture/action path; an acknowledgement alone does not guarantee the model has finished processing.

If a gesture fails, check the bridge’s Connection and Activity pages, confirm Codex is available, and check Accessibility/Bluetooth permissions. After changing pairings or switching between official and source-built variants, pair explicitly with the intended bridge. For questions, use [Help](https://deepinteractionlab.github.io/trackypady/support/).
