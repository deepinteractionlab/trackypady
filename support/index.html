Trackypady

Help.

Trackypady is an iPhone gesture companion for Codex on your Mac. Start with the local demo, or pair with Trackypady Bridge for live controls.

What you need

  • An iPhone running iOS 16 or later, with Bluetooth enabled. QR scanning requires a supported camera; you can also use the regular iPhone Camera app.
  • For Bridge 0.1.0 (52): an Apple silicon Mac running macOS 14 or later. This installer does not support Intel Macs.
  • A working Codex desktop installation on the Mac, with any account/access it requires. Trackypady is independent of Codex and does not include a Codex account.

Trackypady uses Bluetooth, so the devices must be nearby. Keep the phone app open while using it. The phone controls dictation; audio comes from the microphone selected in Codex on the Mac.

Install and pair

  1. Download Bridge 0.1.0 (52) on your Mac. Open its DMG, copy Trackypady Bridge to Applications and launch it. The download is Developer ID signed and notarized by Apple.
  2. Allow Bluetooth on both devices. Grant Trackypady Bridge Accessibility access in System Settings → Privacy & Security → Accessibility.
  3. Open Codex and its intended chat. Use the Bridge Setup page to check/configure Codex shortcuts when needed. Restart Codex when idle if Setup asks you to.
  4. In Trackypady on iPhone, choose Scan to pair and scan the Bridge QR. Or scan with iPhone Camera and tap the banner. If you install the phone app after scanning, open it and scan again.

Gesture quick reference

  • Bring Codex forward: double tap with three fingers.
  • Dictate: hold three fingers, speak to the Mac microphone, then release to stop.
  • Steering: swipe up and release.
  • Queue: swipe up, keep holding still through the Queue hold, then release after confirmation.
  • Select/discard: swipe down to select the draft; swipe down again to delete the current selection. Start with disposable text.
  • Stop: make a deliberate horizontal scratch. Finger-count options and timing are shown in Bridge Gestures.

Swipe finger-count options are configured in Bridge. Action feedback can acknowledge a command being sent without confirming that Codex completed it. Check the Mac when a result is uncertain; avoid blindly repeating a send.

If something does not work

  • Disconnected: keep Bridge running and the iPhone app foreground, check Bluetooth and bring the devices nearby. Reopening the phone app should reconnect a saved pairing.
  • Camera denied: enable Camera in Settings → Apps → Trackypady. Alternatively scan with the iPhone Camera app.
  • Accessibility warning: enable the installed Trackypady Bridge in Mac System Settings. If an old entry remains after an identity change, choose the current installed app.
  • Dictation: bring the intended Codex chat forward, check its microphone manually and select the correct Mac input. Check Bridge Activity for details.
  • Forget/re-pair: use Forget in Bridge Connection. On the phone, six quick one-finger taps clear the saved pairing. If the other device is offline, revocation notification can remain pending; reconnect nearby, then scan a fresh QR.

Codex updates can change shortcuts and controls. Use supported current builds and check Bridge Setup before relying on live commands.
